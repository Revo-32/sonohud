# 배포 라이브러리의 소스
- **YamlDotNet 18.1.0**: https://github.com/aaubry/YamlDotNet/tree/748334a8fa7c227740018b284b71ad95cc6b7fc7 — 공급 NuGet의 repository commit. YamlDotNet/에 수정 가능한 라이브러리 소스, 공통 프로젝트 설정 및 두 라이선스를 포함했다. 공식 패키지를 변경 없이 복원하는 앱 빌드는 scripts/Build-Portable.ps1을 사용한다. 라이브러리를 직접 수정하여 빌드할 때는 YamlDotNet 폴더에서 `dotnet build YamlDotNet/YamlDotNet.csproj -c Release -f net10.0 -p:SignAssembly=false`를 사용할 수 있다. 공급자 서명 개인키는 배포하지 않는다. 자체 수정 빌드의 서명/바이트 일치는 기대하지 않는다.
- **.NET apphost 10.0.12**: .NET SDK 10.0.401이 x64 실행 템플릿을 제공한다. 이 템플릿과 SonoHUD 리소스로 SonoHUD.exe를 생성한다. dotnet-runtime/에 해당 버전의 네이티브 호스트, 공용 헤더와 네이티브 빌드 스크립트를 제공한다. 전체 Microsoft 빌드 트리와 모든 도구는 https://github.com/dotnet/dotnet/tree/95017c711e6afc1085133d440e42b4bd78155701 및 https://github.com/dotnet/runtime/tree/4271d88e0aebf3d04f188f1334c2220d80555ef6 에 있다. 두 커밋의 연결은 https://github.com/dotnet/dotnet/blob/95017c711e6afc1085133d440e42b4bd78155701/src/source-manifest.json 에서 확인할 수 있다. Windows Desktop Runtime은 사용자 설치 구성 요소다.
- **Velopack**: 1.2.161의 .NET 클라이언트 및 Windows 설치기 편집 소스는 Velopack/에 있습니다. scripts/Build-Velopack-Windows.ps1과 BUILD-EMBEDDED.md를 참조하십시오.
- **Embedded WinRT**: 별도 허용 라이선스 Windows.winmd 및 CsWinRT 런타임 소스는 third_party/, 해시·재생성 프로젝트 설정은 BUILD-EMBEDDED.md에 있다.
