# SonoHUD Core 개인정보·외부 서비스

Core는 Windows 미디어 세션에서 곡명·앨범·아티스트·앨범아트와 재생 위치를 읽어 사용자 PC에 표시합니다. 기본 제품에는 온라인 가사를 조회하는 공급 구현이 없으며 곡 정보를 외부 가사 서비스에 전송하지 않습니다. 텔레메트리나 앱 로그의 자동 전송은 없습니다. 스펙트럼은 시스템 출력 오디오를 메모리에서 분석하며 오디오 파일을 만들지 않습니다.

설정·백업·로컬 로그와 사용자가 설치한 확장은 사용자별로 저장합니다. 로그에는 오류 유형·코드, 소스 앱 식별자, 일부 재생 명령·요청 위치나 창 상태가 남을 수 있습니다. 문제 제보 시 필요한 부분을 검토해 공유하세요. 플러그인은 활성화 후 앱과 같은 Windows 사용자 권한으로 코드를 실행합니다. 플러그인별 외부 서비스·전송 항목·이용 조건과 콘텐츠 권리를 확인한 뒤 이용하세요.

설치형은 프로젝트의 공식 GitHub Releases에서 Stable 업데이트 목록과 분리 서명을 받아 새 버전이 있는지 확인합니다. 패키지는 사용자가 선택하면 내려받습니다. [공식 배포 채널](https://github.com/Revo-32/sonohud/releases/latest) 해시는 파일의 무결성을 비교하는 값입니다. 게시자 인증과 Windows 보안 경고는 별도로 확인하세요.
