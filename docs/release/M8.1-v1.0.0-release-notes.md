# SonoHUD Core v1.0.0

Windows에서 듣는 곡을 Home·Mini Player·작업 표시줄 위젯·데스크톱 오버레이에 표시합니다. Windows 11 x64 및 .NET 10 Desktop Runtime x64가 대상입니다. 이 문서는 첫 공개 게시용으로 준비했습니다.

- **재생**. SMTC 세션이 제공하는 앨범 커버, 메타데이터와 재생 상태를 표시합니다. 이전·재생·일시정지·다음·탐색은 플레이어가 지원하는 범위에서 작동합니다.
- **표시**. Windows Composition 오버레이 7종, 6개 테마, Prism RGB, FFT 스펙트럼과 작업 표시줄 위젯을 제공합니다. 주사율과 실제 갱신 빈도는 화면·음악·장비에 따라 달라집니다.
- **확장**. Core는 단독으로 실행합니다. 별도로 구한 신뢰할 수 있는 확장을 승인하면 확장이 제공하는 기능과 가사 전용 디자인을 사용할 수 있습니다. 업데이트 시 기존 확장과 사용자 설정을 보존합니다.
- **설치와 업데이트**. 사용자별 설치형은 로그인 시 트레이 시작과 서명이 검증된 Stable 업데이트를 지원합니다. Portable은 새 ZIP을 받아 새 폴더에 풉니다. Setup 및 앱은 Windows 게시자 무서명입니다.
- **제한**. 음악 탐색 위치는 원 플레이어가 늦게 갱신할 수 있습니다. 위젯 표시 여부는 Explorer와 모니터 구조에 따라 달라집니다. 실제 재로그인·Explorer 재시작·게임 부하·120Hz 이상은 이번 인수 환경에서 확인하지 못했습니다. [설치 안내](core-user-guide.md) · [알려진 제한](known-limitations.md) · [변경 내역](../../CHANGELOG.md)

### English

SonoHUD Core 1.0.0 adds a shared Home and Mini Player interface for Windows media sessions, a taskbar widget, seven Composition overlay designs, six themes including Prism RGB, FFT spectrum and separately approved extension support. The per-user installer supports signed stable updates and optional tray startup at Windows sign-in. Portable updates are manual. Both Windows executables are unsigned.
