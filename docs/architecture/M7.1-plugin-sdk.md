# 확장 SDK API 1

Windows x64용 .NET 10 관리형 클래스 라이브러리에서 `SonoHUD.PluginContracts` 프로젝트를 참조한다. 공개 계약 어셈블리 버전은 1.0.0.0이다. 가사 입력/출력은 공통 Core 값 타입을 사용한다. SDK와 Core를 확장 폴더에 다시 배포할 필요가 없다. 공개 계약은 WPF를 요구하지 않는다.

## 최소 확장

```csharp
using System.Reflection;
using SonoHUD.PluginContracts;

[assembly: AssemblyMetadata("SonoHUD.Plugin", """{"id":"example.basic","name":"기본 확장","version":"1.0.0","minApi":1,"maxApi":1,"entry":"Example.BasicPlugin","capabilities":[],"permissions":[]}""")]

namespace Example;

public sealed class BasicPlugin : ISonoHudPlugin
{
    public void Initialize(PluginContext context) { }
    public void Dispose() { }
}
```

확장 선언은 주 DLL의 `AssemblyMetadataAttribute`에 UTF-8 JSON으로 넣는다. 루트 네임스페이스를 포함한 진입 타입 이름과 공개 기본 생성자가 필요하다.

| 항목 | 의미 |
|---|---|
| id, name, version | 고유 ID, 사용자가 보는 이름, `System.Version` 형식 버전. ID는 소문자 영문으로 시작하며 소문자 영문·숫자·점·밑줄·하이픈을 사용한다. Windows 예약 이름은 사용할 수 없다. |
| minApi, maxApi | 닫힌 정수 호환 범위. 이 릴리스의 API는 1이다. 호환 범위와 동의를 모두 통과한 뒤 초기화한다. |
| entry | ISonoHudPlugin을 구현하는 구체 클래스의 전체 타입 이름. |
| capabilities | 기본 확장은 빈 배열. 가사 공급자를 제공하면 `lyrics`를 선언하고 ILyricsProvider를 구현한다. 미지원 기능은 호환 오류로 표시한다. |
| permissions | 사용자가 승인할 때 확인할 접근 목록. 예를 들어 곡 정보, 네트워크 서비스 이름을 명시한다. |
| providerName, disclosure | 선택적 출처 표시명과 사용자 데이터 전송 안내. 공급처·메타데이터 범위·보관 정책은 확장에서 정확히 표시한다. |
| importLegacyLyricsPreferences | 기본 false. 기존 곡별 선택 ID·보정·검색 설정과 실제 호환되는 공급자만 true로 지정한다. 동의창에 가져오기 사실이 표시된다. 개인별 설정은 처음 활성화한 뒤 별도로 저장한다. |

`PluginContext.SettingsDirectory`는 프로필·확장 ID별 저장 공간이다. `HostVersion`은 실제 앱 버전이다. Initialize는 UI 스레드를 점유하지 않도록 짧게 처리하고, Dispose에서 이벤트·요청·타이머·파일을 정리한다. 향후 지원이 필요한 기능은 API 버전으로 합의한다.

## 가사 공급 기능

`ILyricsProvider.LookupAsync(track, preference, listCandidates, cancellationToken)`는 신규 곡이나 재검색의 최종 일치 또는 후보를 반환한다. `LyricTrack`의 제목·아티스트·앨범·재생시간은 미디어 세션에서 제공된 범위만 사용한다. 후보 선택은 `SelectAsync(recordId, cancellationToken)`로 처리한다. 서비스 요청·기한·오류·매칭 기준은 공급자 책임이며, 취소를 즉시 전파하고 가사 원문을 로그에 쓰지 않는다. `LyricsRequestException`은 사용자에게 표시할 안전한 메시지, 필요하면 재시도 시각을 담는다.

`LyricsLookup`에는 최종 `LyricRecord` 또는 후보 목록을 담는다. 연주곡/일반 텍스트/줄 타임스탬프/지원되는 단어 포맷을 표현할 수 있다. 호스트는 후보 표시 시 본문을 제외하고 최대 32개로 제한한다. 제공자를 떠나면 메모리 문서·후보·검색 상태를 지운다. 가사 없는 코어에는 공급자용으로 비워둔 패널이나 경고가 나타나지 않는다.

단일 DLL은 설정에서 설치하거나 Plugins에 직접 복사한다. 종속 DLL은 주 DLL과 같은 하위 디렉터리에 나란히 둔다. 한 묶음은 총 64 MiB, 최대 32개 파일과 주 선언 하나까지 지원한다. 링크·하위 디렉터리·네이티브 전용 파일은 이 계약의 지원 대상 밖이다. 전체 확장과 종속성에 대한 동의를 확인한 뒤 같은 관리형 코드가 프로세스에 로드된다. 설치와 활성화 및 공개 범위를 구분한다.
